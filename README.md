# 🎬 Movie Explorer

**Movie Explorer** is a simple web application built as part of a company training period to learn and practice Angular development. It integrates with the [OMDb API](https://www.omdbapi.com/) to display information about movies, including search functionality, featured movies, and more.

## 🧪 Technologies Used

- **Angular 19** — Frontend framework
- **OMDb API** — Open Movie Database API for fetching movie data
- **Bootstrap 5** — For responsive layout and UI styling
- **ngx-slick-carousel** — For movie sliders
- **TypeScript, SCSS, HTML**
